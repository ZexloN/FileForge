# 🗂️ FileForge

FileForge is a lightweight Python command-line tool that automatically organizes files into categorized folders based on their file extensions.

It is designed to quickly clean up messy folders such as Downloads, Desktop or custom directories.

## ✨ Features

- 📁 Automatic file organization
- 🖼️ Image detection
- 🎥 Video detection
- 🎵 Audio detection
- 📄 Document detection
- 📊 Spreadsheet detection
- 📊 Presentation detection
- 📦 Archive detection
- 💻 Application detection
- 💻 Source code detection
- 🔤 Font detection
- 📋 Unknown file handling
- 🛡️ Prevents file overwriting
- ⚡ Lightweight and fast
- 📦 No external dependencies

## 🛠️ Technologies

- Python 3
- `pathlib`
- `shutil`
- `sys`

FileForge only uses Python's standard library.
